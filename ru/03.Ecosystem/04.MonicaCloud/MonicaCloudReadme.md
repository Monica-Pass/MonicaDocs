# Monica Cloud

> Облачное направление Monica: опциональная синхронизация, резервное копирование и восстановление между устройствами для локальных клиентов.  
> Cloud · Sync · Backup · Recovery

::: note Аннотация
Monica Cloud — облачное направление в экосистеме паролей Monica. Оно продолжает локально-ориентированный подход и служит лишь опциональным каналом синхронизации и резервного копирования, не меняя принципа хранения основных данных на устройствах пользователя. Сейчас проект находится на стадии планирования и разработки.
:::

---

## Позиционирование

Monica Cloud рассчитан на пользователей, которым нужны кросс-устройственная синхронизация, удалённое резервное копирование и восстановление. Цели:

- Синхронизация учётных данных со сквозным шифрованием
- Автоматическое и ручное резервное копирование
- Восстановление на нескольких устройствах

## Текущее состояние

- Проект находится на ранней стадии разработки; конкретные возможности и сроки будут объявлены позже.
- Основные данные остаются локальными; облачные функции — опциональное расширение, а не обязательная зависимость.

## Связь с экосистемой

- Monica: локальное хранилище паролей и подход к продукту
- Monica Cloud: опциональный канал облачной синхронизации и резервного копирования
