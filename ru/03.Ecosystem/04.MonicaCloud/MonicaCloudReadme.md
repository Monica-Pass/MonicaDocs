# Monica Cloud

> Monica Cloud планируется как необязательный сервис синхронизации, резервного копирования и восстановления для локальных клиентов.<br>
> Cloud · Sync · Backup · Recovery

::: note Аннотация
Monica Cloud — планируемый самостоятельно размещаемый сервис, сейчас на стадии прототипа.
:::

---

## Позиционирование

Monica Cloud рассчитан на пользователей, которым нужны кросс-устройственная синхронизация, удалённое резервное копирование и восстановление. Цели:

- Синхронизация учётных данных со сквозным шифрованием
- Автоматическое и ручное резервное копирование
- Восстановление на нескольких устройствах

## Текущее состояние

- В [репозитории Monica Cloud](https://github.com/Monica-Pass/Monica-Cloud) сейчас есть только прототип WebUI с тестовыми данными; API сервера ещё не реализован, синхронизация и резервное копирование остаются планами.
- Проект находится на ранней стадии разработки; конкретные возможности и сроки будут объявлены позже.
- Основные данные остаются локальными; облачные функции — опциональное расширение, а не обязательная зависимость.

## Связь с экосистемой

- Monica: локальное хранилище паролей и подход к продукту
- Monica Cloud: планируемый необязательный канал синхронизации и резервного копирования
