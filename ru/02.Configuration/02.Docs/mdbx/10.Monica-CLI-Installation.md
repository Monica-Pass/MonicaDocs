# Установка и выпуски Monica CLI

1.0.101 — первый официальный выпуск с пакетами Linux и Windows x86_64. Для готовых программ Rust не нужен.

## Загрузка и платформы

- [GitHub Release 1.0.101](https://github.com/Monica-Pass/Monica-cli/releases/tag/v1.0.101)
- [Windows x86_64 ZIP](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-windows-x86_64.zip)
- [Linux x86_64 tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-linux-x86_64.tar.gz)
- [Source tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-source.tar.gz)
- [SHA256SUMS](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/SHA256SUMS)

Нужны Windows 10/11 x64 или Linux с glibc 2.35+ (например, Ubuntu 22.04+ или Debian 12+). Пакеты Alpine/musl, ARM64 и macOS не входят в этот выпуск.

Загрузите архив и SHA256SUMS, проверьте хеш и распакуйте в отдельную папку с правом записи. Запустите monica.exe или ./monica. Маркер monica-pass.portable сохраняет данные в соседней папке data/. Перед обновлением закройте Monica и сохраните data/, хранилища и все сопутствующие файлы.

В Windows скрипт scripts/install.ps1 -InstallDir D:\Apps\MonicaCLI устанавливает программу для текущего пользователя. -NoPath -NoShortcut отключает изменения PATH и ярлыков. Бинарный файл Windows не подписан. В Linux копирование только программы в PATH без маркера включает каталог состояния XDG.

Модели могут работать через локальный прокси или прямую конфигурацию. Файлы прямого подключения и их копии содержат исходный Key. Сроки, лимиты, отзыв и блокировка Monica на них не действуют; отзывайте или заменяйте Key у провайдера.

Архив исходников содержит CLI, фиксированную версию MDBX и зависимости из lock-файла. Установите Rust 1.97.0 и C toolchain, затем выполните cargo build --release --locked --offline в monica-pass-cli/. BUILD-INFO.json содержит точные ревизии, платформу и хеш программы.

```sh
./monica --version
./monica direct-config manual --client codex --api-base https://models.example.test --model YOUR_MODEL --output ./codex-direct/config.toml
```
