# Ключи Android и локальный прокси моделей

Monica использует API Key из хранилища MDBX Android и создаёт локальный адрес и отзывной локальный ключ. Исходный ключ провайдера остаётся внутри брокера.

Выполните команды в своём терминале. ENTRY_ID — UUID из library. Введите мастер-пароль по запросу.

```sh
monica library
monica bind work-ai --entry <ENTRY_ID> --protocol openai
monica grant model-client --connection work-ai --repo "*" --operation model-list --operation model-invoke --ttl-minutes 240 --max-calls 1000
monica proxy-config model-client --output ./model-client.json
monica serve
```

Настройте доверенный клиент по полям base_url и api_key приватного JSON-файла. Не добавляйте файл в Git или запросы модели. OpenAI: http://127.0.0.1:47831/v1; Anthropic: http://127.0.0.1:47831. Для Anthropic привяжите другой сохранённый ключ с --protocol anthropic. Преобразования протоколов и автоматического переключения нет.

Поддерживаются JSON и SSE: OpenAI responses/chat completions, Anthropic messages/count_tokens, а также models. Внешний сервер должен использовать HTTPS. WebSocket и фоновые Responses не поддерживаются.

По умолчанию serve работает 5 минут. --session-minutes 60 меняет только время работы процесса. Tiga Multi по умолчанию требует свежую аутентификацию в пределах 5 минут, поэтому доступ может прекратиться раньше. Запустите serve снова с мастер-паролем; автоматической разблокировки нет.

После renew повторите proxy-config с --force и перечитайте конфигурацию клиента. revoke отзывает разрешение, unbind сохраняет исходную запись Android. После редактирования записи нужны bind --replace и новое разрешение.

Проверено на временном MDBX и локальном TLS-сервере с синтетическими ключами. Интеграция с реальными провайдерами, Codex и Claude Code ещё не проверена.
