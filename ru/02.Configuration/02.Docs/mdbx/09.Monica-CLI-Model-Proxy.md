# Ключи Android и локальный прокси моделей

> **1.0.101** · [Установка и выпуски Monica CLI](/ru/reference/monica-cli-installation) · [GitHub Release](https://github.com/Monica-Pass/Monica-cli/releases/tag/v1.0.101)

Monica использует API Key из хранилища MDBX Android и создаёт локальный адрес и отзывной локальный ключ. Исходный ключ провайдера остаётся внутри брокера.

Выполните команды в своём терминале. ENTRY_ID — UUID из library. Введите мастер-пароль по запросу.

```sh
monica library
monica bind work-ai --entry <ENTRY_ID> --protocol openai
monica grant model-client --connection work-ai --repo "*" --operation model-list --operation model-invoke --ttl-minutes 240 --max-calls 1000
monica proxy-config model-client --output ./model-client.json
monica serve --proxy-grant model-client --session-minutes 60
```

Настройте доверенный клиент по полям base_url и api_key приватного JSON-файла. Не добавляйте файл в Git или запросы модели. OpenAI: http://127.0.0.1:47831/v1; Anthropic: http://127.0.0.1:47831. Для Anthropic привяжите другой сохранённый ключ с --protocol anthropic. Преобразования протоколов и автоматического переключения нет.

Поддерживаются JSON и SSE: OpenAI responses/chat completions, Anthropic messages/count_tokens, а также models. Внешний сервер должен использовать HTTPS. WebSocket и фоновые Responses не поддерживаются.

Запустите `monica serve --proxy-grant model-client --session-minutes 60` и введите мастер-пароль, чтобы явно разрешить часовую сессию прокси для указанного разрешения. Для нескольких разрешений повторите `--proxy-grant`. При запуске выводится фактический срок каждой сессии (JSON: `ready.data.proxy_sessions`). Прокси может работать дольше обычного пятиминутного окна свежей аутентификации и простоя, но ограничен абсолютным сроком Tiga (Multi по умолчанию: два часа с разблокировки), временем процесса и сроком разрешения. Более строгие политики записи и коллекции сохраняются. Обычный доступ к секретам и MCP не продлевается. Без нового параметра остаются прежние проверки; время процесса по умолчанию — пять минут.

Блокировка, отзыв, изменение исходной записи или политики и истечение срока останавливают сессию. Для повторного разрешения человек снова запускает ту же команду serve с мастер-паролем. Действующее разрешение с оставшимся бюджетом сохраняет локальный ключ. Сессия существует только в памяти и не восстанавливается после перезапуска или разблокировки. Формат базы и поля API Key не меняются; Android может использовать прежний движок. Автоматической разблокировки нет.

После renew повторите proxy-config с --force и перечитайте конфигурацию клиента. revoke отзывает разрешение, unbind сохраняет исходную запись Android. После редактирования записи нужны bind --replace и новое разрешение.

Проверено на временном MDBX и локальном TLS-сервере с синтетическими ключами. Интеграция с реальными провайдерами, Codex и Claude Code ещё не проверена.

## Прямое подключение: исходный Key в настройках клиента

Чтобы обойти прокси Monica, используйте `direct-config manual` для ввода Key или `direct-config saved` для уже привязанного Android API Key. Команды создают настройки Codex / Claude Code. Путь вывода обязателен; настройки клиентов на хосте автоматически не выбираются.

```sh
monica direct-config manual --client codex --api-base https://models.example.test --model YOUR_MODEL --output ./codex-direct/config.toml
monica direct-config saved work-ai --client claude --model YOUR_CLAUDE_MODEL --output ./claude-direct/settings.json
```

Ручной режим использует скрытый ввод либо `--secrets-stdin` с `{"token":"..."}`. Сохранённый Key требует мастер-пароль (`{"password":"..."}`), останавливает текущий broker и проверяет разрешения Tiga на экспорт и раскрытие. Запрет экспорта соблюдается, аренда прокси не используется. Для Codex нужна привязка OpenAI, для Claude Code — Anthropic.

Codex добавляет `/v1` к адресу без пути. Claude Code убирает завершающий `/v1`, чтобы SDK добавил путь запроса. Нужны HTTPS API base и точный ID модели, а не полный адрес `/responses` или `/messages`.

Для существующего файла требуется `--force`. Посторонние настройки сохраняются; перед изменением создаётся приватная копия `.monica-<UUID>.bak`. Некорректные и неоднозначные файлы не изменяются. Повтор без изменений не создаёт лишних копий. Права: Unix 0600 / приватный Windows ACL.

**В файле хранится исходный Key открытым текстом.** Сроки, лимиты, отзыв разрешений и блокировка Monica не влияют на прямые запросы. Для отключения отзовите или замените Key у провайдера и обновите настройки и копии. Исходные данные Android сохраняются; аудит и существующее восстановление корневой категории могут записывать данные в хранилище.
