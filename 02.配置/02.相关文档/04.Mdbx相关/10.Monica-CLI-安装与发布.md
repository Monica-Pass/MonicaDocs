# Monica CLI 安装与发布

1.0.101 是首个同时提供 Linux 与 Windows x86_64 包的正式版本。二进制包无需安装 Rust。

## 下载与平台

- [GitHub Release 1.0.101](https://github.com/Monica-Pass/Monica-cli/releases/tag/v1.0.101)
- [Windows x86_64 ZIP](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-windows-x86_64.zip)
- [Linux x86_64 tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-linux-x86_64.tar.gz)
- [Source tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-source.tar.gz)
- [SHA256SUMS](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/SHA256SUMS)

Windows 包需要 Windows 10/11 x64；Linux 包需要 glibc 2.35+，例如 Ubuntu 22.04+、Debian 12+。Alpine/musl、ARM64 和 macOS 不在本次二进制包范围内。

下载对应的压缩包和 SHA256SUMS，核对校验值，再解压到可写的独立目录。运行 monica.exe 或 ./monica。便携标记 monica-pass.portable 使数据保存在旁边的 data/；升级时关闭 Monica，保留整个 data/、保险库与附属文件。

Windows 可在解压目录运行 scripts/install.ps1 -InstallDir D:\Apps\MonicaCLI 安装到当前用户；脚本可添加 PATH 与快捷方式，使用 -NoPath -NoShortcut 可跳过。Windows 程序尚未代码签名。Linux 直接运行，也可以只将程序复制到 PATH；不复制便携标记时使用 XDG 状态目录。

模型可以使用本地代理或直连配置。直连文件与备份包含原始 Key；Monica 授权期限、次数、撤销和锁库不适用于直连，应在上游轮换或撤销 Key。

源码包包含 CLI、固定 MDBX 提交和锁定的第三方依赖。安装 Rust 1.97.0 与 C 工具链后，在 monica-pass-cli/ 执行 cargo build --release --locked --offline。每个二进制包的 BUILD-INFO.json 记录版本、源码提交、引擎提交、构建目标和二进制哈希。

```sh
./monica --version
./monica direct-config manual --client codex --api-base https://models.example.test --model YOUR_MODEL --output ./codex-direct/config.toml
```
