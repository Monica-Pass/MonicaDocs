# Monica Cloud

> ローカルファーストのクライアント向けに、任意のクロスデバイス同期・バックアップ・復旧を提供するクラウドサービス。  
> Cloud · Sync · Backup · Recovery

::: note 概要
Monica Cloud は Monica パスワードエコシステムにおけるクラウドサービスです。ローカルファーストの方針を継承し、あくまで任意の同期・バックアップ経路として提供します。中核となる認証情報がユーザーの端末に残るという原則は変わりません。現在は計画・開発段階です。
:::

---

## プロジェクトの位置づけ

クロスデバイス同期、リモートバックアップ、復旧を必要とするユーザーに向けて、以下を提供することを目指します：

- エンドツーエンド暗号化による認証情報の同期
- 自動・手動バックアップ
- マルチデバイス復旧

## 現在の状態

- プロジェクトは初期開発段階にあり、具体的な機能とリリース時期は順次公開予定です。
- 中核データは引き続きローカル優先で、クラウド機能は任意の拡張であり強制ではありません。

## エコシステムとの関係

- Monica：ローカルファーストのパスワード管理と製品理念
- Monica Cloud：任意のクラウド同期・バックアップ経路
