# Monica Cloud

> Monica Cloud は、ローカルファーストのクライアントに任意の同期・バックアップ・復旧を提供することを目指しています。<br>
> Cloud · Sync · Backup · Recovery

::: note 概要
Monica Cloud は計画中のセルフホスト型サービスで、現在はプロトタイプ段階です。
:::

---

## プロジェクトの位置づけ

クロスデバイス同期、リモートバックアップ、復旧を必要とするユーザーに向けて、以下を提供することを目指します：

- エンドツーエンド暗号化による認証情報の同期
- 自動・手動バックアップ
- マルチデバイス復旧

## 現在の状態

- [Monica Cloud リポジトリ](https://github.com/Monica-Pass/Monica-Cloud)には現在、模擬データを使う WebUI プロトタイプのみがあり、バックエンド API は未実装です。同期とバックアップは計画段階です。
- プロジェクトは初期開発段階にあり、具体的な機能とリリース時期は順次公開予定です。
- 中核データは引き続きローカル優先で、クラウド機能は任意の拡張であり強制ではありません。

## エコシステムとの関係

- Monica：ローカルファーストのパスワード管理と製品理念
- Monica Cloud：計画中の任意のクラウド同期・バックアップ経路
