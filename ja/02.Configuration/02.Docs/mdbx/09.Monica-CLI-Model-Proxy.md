# Android API Key とローカルモデルプロキシ

Android の MDBX に保存した API Key を参照し、Monica がローカル URL と取り消し可能なローカル Key を生成します。上流の秘密鍵はクライアントに渡しません。

本人の端末で実行します。ENTRY_ID は library の UUID です。要求されたらマスターパスワードを入力します。

```sh
monica library
monica bind work-ai --entry <ENTRY_ID> --protocol openai
monica grant model-client --connection work-ai --repo "*" --operation model-list --operation model-invoke --ttl-minutes 240 --max-calls 1000
monica proxy-config model-client --output ./model-client.json
monica serve
```

JSON の base_url と api_key を信頼できるクライアントに設定します。ファイルを Git やプロンプトに含めないでください。OpenAI は http://127.0.0.1:47831/v1、Anthropic は http://127.0.0.1:47831 です。Anthropic 用の保存済み Key は --protocol anthropic で別にバインドします。プロトコル変換や自動切替はありません。

JSON と SSE に対応します。OpenAI は responses/chat completions、Anthropic は messages/count_tokens、両方で models を利用できます。上流は HTTPS のみです。WebSocket とバックグラウンド Responses は未対応です。

serve の既定は 5 分です。--session-minutes 60 はプロセスの上限だけを延長します。Tiga Multi の既定では 5 分以内の新しい認証が必要なため、それより早く再度 serve を実行する必要があります。自動再解錠はありません。

renew 後は proxy-config --force で更新してクライアントに再読込します。revoke は権限を取り消し、unbind は元の Android 項目を残します。元の項目を編集した場合は bind --replace と再承認が必要です。

一時 MDBX とローカル TLS 模擬上流で検証済みです。実サービス、Codex、Claude Code の接続試験は未実施です。
