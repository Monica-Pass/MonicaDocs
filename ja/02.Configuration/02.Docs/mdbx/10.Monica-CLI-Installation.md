# Monica CLI インストールとリリース

1.0.101 は Linux と Windows x86_64 パッケージを提供する最初の正式リリースです。バイナリの利用に Rust は不要です。

## ダウンロードと対応環境

- [GitHub Release 1.0.101](https://github.com/Monica-Pass/Monica-cli/releases/tag/v1.0.101)
- [Windows x86_64 ZIP](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-windows-x86_64.zip)
- [Linux x86_64 tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-linux-x86_64.tar.gz)
- [Source tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-source.tar.gz)
- [SHA256SUMS](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/SHA256SUMS)

Windows 10/11 x64、または glibc 2.35+ の Linux（Ubuntu 22.04+、Debian 12+ など）が必要です。Alpine/musl、ARM64、macOS のバイナリは含みません。

対応アーカイブと SHA256SUMS を取得してハッシュを確認し、書き込み可能な専用フォルダーに展開します。monica.exe または ./monica を起動します。monica-pass.portable がある場合、データは隣の data/ に保存されます。更新前に終了し、data/ と保管庫の関連ファイルを保持してください。

Windows は scripts/install.ps1 -InstallDir D:\Apps\MonicaCLI でユーザー用にインストールできます。-NoPath -NoShortcut で PATH とショートカットの変更を省略できます。Windows 版はコード署名されていません。Linux ではマーカーなしで実行ファイルだけを PATH に配置すると XDG 状態ディレクトリを使用します。

モデルはプロキシまたは直接接続を選択できます。直接接続設定とバックアップには元の Key が含まれます。Monica の期限、回数、失効、ロックは適用されません。停止時は上流で Key を失効・更新してください。

ソースアーカイブには CLI、固定 MDBX ソース、ロック済み依存関係を含みます。Rust 1.97.0 と C ツールチェーンを用意し、monica-pass-cli/ で cargo build --release --locked --offline を実行します。BUILD-INFO.json に正確なリビジョンとハッシュを記録しています。

```sh
./monica --version
./monica direct-config manual --client codex --api-base https://models.example.test --model YOUR_MODEL --output ./codex-direct/config.toml
```
