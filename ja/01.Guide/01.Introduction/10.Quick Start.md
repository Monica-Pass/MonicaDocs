### 迅速なインストール

Android:
1. GitHub の [Releases](https://github.com/Monica-Pass/Monica/releases) ページから最新の APK ファイルをダウンロードします。
2. Android 8.0 以上のデバイスにインストールし、起動後にマスターパスワードを初期設定します。

ブラウザ拡張機能 (Chrome / Edge):
1. 拡張機能の [GitHub Releases](https://github.com/Monica-Pass/Monica-for-Extension/releases) から ZIP をダウンロードし、固定のディレクトリに展開します。
2. `chrome://extensions/` または `edge://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、展開したディレクトリを指定します。更新時は元のディレクトリと拡張機能 ID を維持し、ファイルを置き換えて拡張機能を再読み込みしてから、開いているウェブページを更新します。

### 既知の制限事項
- システムの互換性の原因により、現在、一部のシャオミ製 HyperOS デバイスにおいて、Monica for Android からパスキー（Passkey）を正常に作成できない問題が確認されています。
