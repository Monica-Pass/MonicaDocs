# Cài đặt và phát hành Monica CLI

1.0.101 là bản chính thức đầu tiên có gói Linux và Windows x86_64. Không cần Rust để dùng gói nhị phân.

## Tải xuống và nền tảng

- [GitHub Release 1.0.101](https://github.com/Monica-Pass/Monica-cli/releases/tag/v1.0.101)
- [Windows x86_64 ZIP](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-windows-x86_64.zip)
- [Linux x86_64 tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-linux-x86_64.tar.gz)
- [Source tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-source.tar.gz)
- [SHA256SUMS](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/SHA256SUMS)

Yêu cầu Windows 10/11 x64 hoặc Linux glibc 2.35+ như Ubuntu 22.04+, Debian 12+. Không có gói Alpine/musl, ARM64 hoặc macOS trong bản này.

Tải gói phù hợp và SHA256SUMS, kiểm tra hàm băm rồi giải nén vào thư mục riêng có quyền ghi. Chạy monica.exe hoặc ./monica. Tệp monica-pass.portable giữ dữ liệu ở data/ bên cạnh. Đóng Monica trước khi nâng cấp và giữ nguyên data/, kho cùng các tệp liên quan.

Trên Windows, scripts/install.ps1 -InstallDir D:\Apps\MonicaCLI cài cho người dùng hiện tại. Dùng -NoPath -NoShortcut để bỏ thay đổi PATH và lối tắt. Bản Windows chưa ký mã. Trên Linux, chỉ sao chép chương trình vào PATH mà không có tệp đánh dấu sẽ dùng thư mục trạng thái XDG.

Có thể chọn proxy cục bộ hoặc cấu hình trực tiếp. Tệp trực tiếp và bản sao chứa Key gốc. Thời hạn, hạn mức, thu hồi và khóa của Monica không áp dụng; cần đổi hoặc thu hồi Key tại nhà cung cấp khi ngừng dùng.

Gói nguồn gồm CLI, MDBX cố định và các phụ thuộc đã khóa. Cài Rust 1.97.0 cùng bộ công cụ C rồi chạy cargo build --release --locked --offline trong monica-pass-cli/. BUILD-INFO.json ghi phiên bản, mã commit, nền tảng và hàm băm nhị phân.

```sh
./monica --version
./monica direct-config manual --client codex --api-base https://models.example.test --model YOUR_MODEL --output ./codex-direct/config.toml
```
