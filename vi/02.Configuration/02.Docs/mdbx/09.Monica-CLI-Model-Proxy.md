# API Key Android và proxy mô hình cục bộ

Monica dùng API Key đã lưu trong MDBX trên Android để tạo địa chỉ và Key cục bộ có thể thu hồi. Key thật của nhà cung cấp được giữ trong broker.

Chạy trong terminal của bạn. ENTRY_ID là UUID từ library. Nhập mật khẩu chính khi được yêu cầu.

```sh
monica library
monica bind work-ai --entry <ENTRY_ID> --protocol openai
monica grant model-client --connection work-ai --repo "*" --operation model-list --operation model-invoke --ttl-minutes 240 --max-calls 1000
monica proxy-config model-client --output ./model-client.json
monica serve --proxy-grant model-client --session-minutes 60
```

Cấu hình ứng dụng đáng tin cậy bằng base_url và api_key trong tệp JSON riêng tư. Không đưa tệp vào Git hoặc lời nhắc. OpenAI: http://127.0.0.1:47831/v1; Anthropic: http://127.0.0.1:47831. Với Anthropic, liên kết Key đã lưu khác bằng --protocol anthropic. Không chuyển đổi giao thức hay tự đổi nhà cung cấp.

Hỗ trợ JSON và SSE: OpenAI responses/chat completions, Anthropic messages/count_tokens và models. Máy chủ nguồn phải dùng HTTPS. Chưa hỗ trợ WebSocket hay Responses chạy nền.

Chạy `monica serve --proxy-grant model-client --session-minutes 60` và nhập mật khẩu chính để phê duyệt rõ ràng phiên proxy một giờ cho quyền đã chọn. Lặp lại `--proxy-grant` để chọn nhiều quyền. Khi khởi động, Monica hiển thị hạn thực tế của từng phiên (JSON: `ready.data.proxy_sessions`). Phiên proxy được duyệt có thể vượt cửa sổ xác thực mới năm phút và thời gian nhàn rỗi thông thường, nhưng vẫn bị giới hạn bởi hạn tuyệt đối của Tiga (Multi mặc định: hai giờ từ lúc mở khóa), thời gian tiến trình và hạn của quyền. Chính sách nghiêm ngặt hơn của mục hoặc bộ sưu tập vẫn áp dụng. Quyền đọc bí mật thông thường và MCP không được kéo dài. Nếu bỏ tham số mới, kiểm tra xác thực cũ vẫn áp dụng; tiến trình mặc định vẫn chạy năm phút.

Khóa kho, thu hồi quyền, thay đổi mục nguồn hoặc chính sách và hết hạn sẽ dừng phiên. Người dùng chạy lại cùng lệnh serve với mật khẩu chính để phê duyệt lại. Quyền còn hiệu lực và ngân sách giữ nguyên Key cục bộ. Phiên chỉ nằm trong bộ nhớ, không được khôi phục sau khi khởi động lại hoặc mở khóa lại. Định dạng cơ sở dữ liệu và trường API Key không đổi; Android có thể tiếp tục dùng động cơ hiện tại. Không tự động mở khóa.

Sau renew, chạy lại proxy-config với --force và nạp lại cấu hình ứng dụng. revoke thu hồi quyền; unbind giữ nguyên mục Android. Khi mục nguồn thay đổi, cần bind --replace và cấp quyền mới.

Đã kiểm tra với MDBX tạm thời, Key giả lập và máy chủ TLS cục bộ. Chưa kiểm thử tích hợp nhà cung cấp thật, Codex hoặc Claude Code.

## Kết nối trực tiếp: ghi Key gốc vào cấu hình máy khách

Để bỏ qua proxy Monica, dùng `direct-config manual` với Key nhập tay hoặc `direct-config saved` với Android API Key đã liên kết. Cả hai tạo cấu hình gốc cho Codex / Claude Code. Phải chỉ định tệp đầu ra; không tự chọn cấu hình trên máy chủ.

```sh
monica direct-config manual --client codex --api-base https://models.example.test --model YOUR_MODEL --output ./codex-direct/config.toml
monica direct-config saved work-ai --client claude --model YOUR_CLAUDE_MODEL --output ./claude-direct/settings.json
```

Chế độ thủ công dùng lời nhắc ẩn hoặc `--secrets-stdin` với `{"token":"..."}`. Key đã lưu yêu cầu mật khẩu chính (`{"password":"..."}`), dừng broker hiện tại và kiểm tra quyền xuất lẫn đọc bí mật của Tiga. Không bỏ qua lệnh cấm xuất hoặc dùng phiên proxy để cấp quyền xuất. Codex dùng liên kết OpenAI; Claude Code dùng Anthropic.

Codex thêm `/v1` vào tên miền không có đường dẫn. Claude Code bỏ `/v1` ở cuối để SDK thêm đường dẫn yêu cầu. Chỉ nhận HTTPS API base và ID mô hình cụ thể, không nhận địa chỉ đầy đủ `/responses` hoặc `/messages`.

Tệp có sẵn cần `--force` để hợp nhất. Giữ các thiết lập không liên quan, tạo bản sao riêng tư `.monica-<UUID>.bak` trước khi thay đổi. Từ chối cấu trúc sai hoặc mơ hồ; chạy lại mà không đổi sẽ không tạo thêm bản sao. Quyền tệp: Unix 0600 / Windows ACL riêng tư.

**Tệp chứa Key gốc ở dạng văn bản thuần.** Thời hạn, số lượt, thu hồi và khóa của Monica không kiểm soát yêu cầu trực tiếp. Hãy thu hồi hoặc đổi Key tại nhà cung cấp rồi cập nhật tệp và bản sao để vô hiệu hóa. Dữ liệu Android gốc được giữ nguyên; kiểm toán và sửa danh mục gốc hiện có vẫn có thể ghi vào kho.
