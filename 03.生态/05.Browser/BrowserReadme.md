# Monica for Browser

> Monica 的浏览器端扩展：在网页中完成账号密码的智能自动填充与快捷访问。  
> Browser · AutoFill · Extension

::: note 摘要
Monica for Browser 是 Monica 密码库生态中的浏览器端扩展，聚焦网页场景下的密码自动填充，帮助你在浏览器里快速使用本地保险库中的登录凭据。
:::

---

## 项目定位

- 网页端智能自动填充
- 快捷访问本地保险库中的登录凭据
- 与 Monica Android 等客户端共享同一套凭据模型

## 当前状态

- 浏览器扩展 `Monica-for-Extension` 目前暂停活跃更新，项目优先聚焦 Android 端的功能完善、体验优化与稳定性维护。
- 相关代码与讨论以 [Monica-Pass](https://github.com/Monica-Pass) 组织为准。

## 与生态的关系

- Monica：提供本地保险库与凭据管理
- Monica for Browser：负责浏览器场景的入口与自动填充
