# Monica Cloud

> Monica 的云端服务方向：为本地优先的客户端提供可选的跨设备同步、备份与恢复能力。  
> Cloud · Sync · Backup · Recovery

::: note 摘要
Monica Cloud 是 Monica 密码库生态中的云端服务方向。它延续本地优先的理念，仅作为可选的同步与备份通道，不会改变核心凭据保存在用户设备上的原则。当前处于规划与开发阶段。
:::


## 项目定位

Monica Cloud 面向需要跨设备同步、远程备份与恢复的用户，目标提供：

- 端到端加密的凭据同步
- 自动与手动备份
- 多设备恢复

## 当前状态

- 项目处于早期开发阶段，具体能力与上线时间将陆续公布。
- 核心数据仍以本地存储优先，云端能力为可选增强，不强制依赖。

## 与生态的关系

- Monica：提供本地优先密码库与产品理念
- Monica Cloud：作为可选的云端同步与备份通道
