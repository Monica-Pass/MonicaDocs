# Monica Cloud

> Monica Cloud 旨在为本地优先的客户端提供可选的跨设备同步、备份与恢复。<br>
> Cloud · Sync · Backup · Recovery

::: note 摘要
Monica Cloud 是计划中的自托管服务，目前处于原型阶段。
:::


## 项目定位

Monica Cloud 面向需要跨设备同步、远程备份与恢复的用户，目标提供：

- 端到端加密的凭据同步
- 自动与手动备份
- 多设备恢复

## 当前状态

- 根据 [Monica Cloud 仓库](https://github.com/Monica-Pass/Monica-Cloud)，当前仅有使用模拟数据的 WebUI 原型；后端 API 尚未实现，同步与备份仍属计划功能。
- 项目处于早期开发阶段，具体能力与上线时间将陆续公布。
- 核心数据仍以本地存储优先，云端能力为可选增强，不强制依赖。

## 与生态的关系

- Monica：提供本地优先密码库与产品理念
- Monica Cloud：计划中的可选云端同步与备份通道
