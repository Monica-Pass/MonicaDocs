# Monica CLI Installation and Releases

1.0.101 is the first release with Linux and Windows x86_64 packages. Binary packages do not require Rust.

## Downloads and platforms

- [GitHub Release 1.0.101](https://github.com/Monica-Pass/Monica-cli/releases/tag/v1.0.101)
- [Windows x86_64 ZIP](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-windows-x86_64.zip)
- [Linux x86_64 tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-linux-x86_64.tar.gz)
- [Source tar.gz](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/monica-cli-1.0.101-source.tar.gz)
- [SHA256SUMS](https://github.com/Monica-Pass/Monica-cli/releases/download/v1.0.101/SHA256SUMS)

Windows requires Windows 10/11 x64. Linux requires glibc 2.35+, such as Ubuntu 22.04+ or Debian 12+. Alpine/musl, ARM64 and macOS binaries are not included.

Download the matching archive and SHA256SUMS, verify the checksum, and extract into a writable dedicated folder. Run monica.exe or ./monica. The monica-pass.portable marker keeps local data in the adjacent data/ directory. Close Monica before upgrading and preserve all data, vaults and sidecars.

On Windows, scripts/install.ps1 -InstallDir D:\Apps\MonicaCLI optionally installs for the current user, adds PATH and a shortcut. Use -NoPath -NoShortcut to skip those changes. The Windows binary is not code-signed. Linux can run from the extracted folder; copying only the executable into PATH without the marker selects the XDG state directory.

Model clients can use the local proxy or direct configuration. Direct settings and backups contain the raw upstream Key; Monica expiry, budgets, revocation and locking do not apply. Rotate or revoke the Key upstream when retiring direct access.

The source archive includes the CLI, pinned MDBX source and locked third-party dependencies. With Rust 1.97.0 and a C toolchain installed, run cargo build --release --locked --offline from monica-pass-cli/. Each binary package includes BUILD-INFO.json with versions, source revisions, target and binary hash.

```sh
./monica --version
./monica direct-config manual --client codex --api-base https://models.example.test --model YOUR_MODEL --output ./codex-direct/config.toml
```
