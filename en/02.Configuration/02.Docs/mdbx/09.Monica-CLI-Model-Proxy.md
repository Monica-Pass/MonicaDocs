# Android API Keys and the local model proxy

Bind an API Key already saved in an Android MDBX vault. Monica generates a loopback address and a revocable local key. It injects the upstream secret inside the broker; the model client never needs that secret.

Run these commands in your own terminal. ENTRY_ID is the native UUID from library. Enter the master password when prompted.

```sh
monica library
monica bind work-ai --entry <ENTRY_ID> --protocol openai
monica grant model-client --connection work-ai --repo "*" --operation model-list --operation model-invoke --ttl-minutes 240 --max-calls 1000
monica proxy-config model-client --output ./model-client.json
monica serve
```

The private JSON file contains base_url and api_key. Configure a trusted model client from those fields; keep the file outside version control and prompts. OpenAI uses http://127.0.0.1:47831/v1; Anthropic uses http://127.0.0.1:47831. For Anthropic, bind a separate saved key with --protocol anthropic. One local key selects one upstream; no protocol conversion or automatic failover.

JSON and SSE are supported: OpenAI /v1/responses and /v1/chat/completions; Anthropic /v1/messages and /v1/messages/count_tokens; both support GET /v1/models. HTTPS upstreams only, no redirects. Requests: 16 MiB; responses: 64 MiB; SSE events: 1 MiB; four concurrent upstream calls; 300 seconds per request. No WebSocket, background Responses, model pagination, or dedicated file/audio/image endpoints.

serve defaults to five minutes; --session-minutes 60 extends only the process lifetime (range 1–1440). Tiga remains authoritative: the default Multi profile requires fresh authentication within five minutes, so access can stop earlier even while the broker runs. Re-run serve with the master password. There is no unattended automatic unlock.

Grants expire separately (default 240 minutes, maximum 1440) and may have call budgets. renew rotates the local key: run proxy-config again with --force and reload the client. revoke stops that grant; lock stops the broker; unbind removes only the local binding. Editing the Android source requires bind --replace and new grants. Source payloads, native identity, labels and private notes are preserved.

Validated with temporary MDBX vaults, synthetic credentials and a local TLS upstream. Real provider, Codex and Claude Code end-to-end integration has not been verified.
