### Quick Installation

Android:
1. Download the latest APK build from the official [Releases](https://github.com/Monica-Pass/Monica/releases) page.
2. Install the package on any device running Android 8.0+ and configure your master password.

Browser Extension (Chrome / Edge):
1. Download the ZIP from the extension’s [GitHub Releases](https://github.com/Monica-Pass/Monica-for-Extension/releases) and extract it to a permanent directory.
2. Open `chrome://extensions/` or `edge://extensions/` and enable Developer mode.
3. Choose “Load unpacked” and select the extracted directory. When upgrading, keep the same directory and extension ID, replace the files, reload the extension, and refresh open websites.

### Known Limitations
- Due to system-level configuration variances, Monica for Android is currently unable to initialize or generate Passkeys on certain devices running Xiaomi HyperOS.
