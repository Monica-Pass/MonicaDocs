# Monica Cloud

> Monica Cloud aims to provide optional cross-device sync, backup, and recovery for local-first clients.<br>
> Cloud · Sync · Backup · Recovery

::: note Summary
Monica Cloud is a planned self-hosted service, currently at the prototype stage.
:::

---

## Project positioning

Monica Cloud targets users who need cross-device sync, remote backup, and recovery, aiming to provide:

- End-to-end encrypted credential sync
- Automatic and manual backups
- Multi-device recovery

## Current status

- The [Monica Cloud repository](https://github.com/Monica-Pass/Monica-Cloud) currently contains a WebUI prototype using mock data; the backend API has not been implemented, and sync and backup remain planned.
- The project is in early development; specific capabilities and timelines will be announced later.
- Core data remains local-first; cloud features are optional enhancements, not a hard dependency.

## Relationship to the ecosystem

- Monica: provides the local-first password vault and product philosophy
- Monica Cloud: a planned optional cloud sync and backup channel
