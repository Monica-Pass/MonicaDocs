# Monica Cloud

> Monica's cloud service track: optional cross-device sync, backup, and recovery for local-first clients.  
> Cloud · Sync · Backup · Recovery

::: note Summary
Monica Cloud is the cloud service track in the Monica password ecosystem. It follows the local-first philosophy and serves only as an optional sync and backup channel, without changing the principle that core credentials stay on your devices. It is currently in the planning and development stage.
:::

---

## Project positioning

Monica Cloud targets users who need cross-device sync, remote backup, and recovery, aiming to provide:

- End-to-end encrypted credential sync
- Automatic and manual backups
- Multi-device recovery

## Current status

- The project is in early development; specific capabilities and timelines will be announced later.
- Core data remains local-first; cloud features are optional enhancements, not a hard dependency.

## Relationship to the ecosystem

- Monica: provides the local-first password vault and product philosophy
- Monica Cloud: an optional cloud sync and backup channel
